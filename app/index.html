Install in a few steps

No separate MAo Studio account is needed. Your existing approved Cloudflare Access email is used for sign-in.

01

Download

Select the Windows installer above and save the .exe file.

02

Install

Open the installer and follow Windows setup instructions.

03

Sign in securely

Open MAo Studio and complete your Cloudflare Access verification.

04

Publish

Manage posts and media using the same MAo CMS as the web version.

Before you install

This first version is not digitally code-signed. Windows may show an Unknown publisher or SmartScreen warning. Verify that the file was downloaded from the official MAo website or the official repository before deciding whether to continue. Only authorized MAo staff can access the CMS.

The desktop application needs internet access; CMS passwords and posts are not stored inside the installer.
