GET STARTED

Install in a few steps

No separate MAo Studio account is needed. Your existing approved Cloudflare Access email is used for sign-in.

01

Download

Choose the Windows .exe or Android .apk download for your device.

02

Install

Run Windows Setup, or install the Android APK after reviewing its source and security warning.

03

Sign in securely

Open MAo Studio and complete your Cloudflare Access verification.

04

Publish

Manage posts and media using the same MAo CMS as the web version.

Before you install

The Windows installer is not code-signed and SmartScreen may show an Unknown publisher warning. The Android APK is signed but not distributed through Google Play; Android may request confirmation before installing it. Only download official MAo files, review your device's security warnings, and never disable Play Protect. Only authorized MAo staff can access the CMS.

Both applications require internet. CMS passwords and posts are not embedded in the installers. Android v1.0.0 currently uses a temporary signing certificate; future upgrades may require uninstalling the older APK until a long-term signing key is configured.
