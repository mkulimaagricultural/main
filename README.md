# Mkulima Agricultural Organization (MAo)

Mkulima Agricultural Organization (MAo) is a non-governmental organization based in Mbeya, Tanzania. We support women, young people, and communities through knowledge, resources, and opportunities in productive, sustainable, and climate-resilient agriculture.

## Our website

This is MAo's official website and updates platform. Visitors can learn about the organization and its work, read updates, get in touch, and find donation information. The website is available in English and Kiswahili.

## Ownership

The website and its official content are managed by Mkulima Agricultural Organization (MAo).
