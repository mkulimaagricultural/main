Installation and security

MAo is not yet distributed through Google Play. Your device may ask you to allow installation from the browser or file manager. Only proceed after verifying that the APK came from the official MAo website or GitHub release. Do not disable Play Protect to force installation.

Internet is required to load the latest content. This release uses a temporary self-signed signing certificate; a later upgrade may require uninstalling the previous APK until we configure permanent signing.
